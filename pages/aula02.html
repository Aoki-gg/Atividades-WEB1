Outras tags importantes HTML

  • Elemento de bloco e de linha: De bloco começa em uma nova linha e de linha na mesma linha
  • TAG SPAN: Usada para formatar o elemento dentro dela sem dar significado semantico, é um elemento de linha
  • TAG ADDRESS: Para fins de contato
  • TAG DIV: serve para agrupar um conjunto de elemento para move-los juntos, é um elemento de bloco
  • TAG class: serve para identificar partes da pagina como iguais para formatação, ao mudar o estilo da tag todos os elementos que pertencem a ela mudam junto
  • TAG blockquote: é uma referencia, quotando o texto e referenciando ele, ou seja, onde encontrou
