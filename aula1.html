1.Titulos HTML

2. Paragrafos em HTML

Paragrafos em HTML sao representados pela TAG < p >

Exemplo:

< p > paragrafo com a tag P

3.Formatação

  • < b > < /b > para negrito
  • < i > < /i > para italico
  • < u > < /u > para sublinhado
  • < strong > < /strong > para enfase em negrito
  • < em > < /em > para enfase em italico
  • < br > < /br > para quebra de linha

4. Listas

4.1 Listas nao ordenadas usam a tag <ul > para criar a lista e < li > para criar os itens

  • Item 1
  • Item 2
  • Item 3

4.2 Listas ordenadas usam a tag <ol > para criar a lista e < li > criar os itens

  1. Item 1
  2. Item 2
  3. Item 3

4.3 Listas ordenadas usam a tag < dl > para criar a lista e < dt > para criar os itens e < dd > para criar sub termos

5. Links de referencia para outras paginas

Links de referencia são usados pela TAG < a href="LINK" >

Os link podem ser tanto para paginas externas, como também arquivo do proprio projeto ou até mesmo um lugar da pagina atual (ancora)

  • Pagina do projeto
  • Pagina externa
  • Ancora para o inicio da pagina

6. Codigo de programa

Usamos a TAG <code > para usar um código de programa
